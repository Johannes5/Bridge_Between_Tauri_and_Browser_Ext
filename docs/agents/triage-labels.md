# Triage Labels

This repo uses the default label vocabulary.

| Canonical role | Label string |
|---|---|
| Needs evaluation | `needs-triage` |
| Waiting on reporter | `needs-info` |
| Ready for AFK agent | `ready-for-agent` |
| Needs human implementation | `ready-for-human` |
| Will not be actioned | `wontfix` |

Category labels: `bug`, `enhancement`
